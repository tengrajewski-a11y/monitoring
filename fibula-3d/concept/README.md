# Concept pictures of the custom creature models

Each picture was generated with `tools/concept_generate.py` (LCM Dreamshaper v7, MIT) and turned
into `client/assets/models/custom/<key>.glb` with `tools/local_generate.py` (TripoSR, MIT).
The prompt is the description below followed by the style text in `concept_generate.py`.

| Creature | Description | Seed | TripoSR settings |
| --- | --- | --- | --- |
| wolf | a grey wolf monster with dark back fur and a pale belly, standing on all four legs | 7722 | `--height 0.75 --faces 3000 --resolution 256`, rotY 60 |
